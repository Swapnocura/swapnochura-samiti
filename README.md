স্বপ্নচূড়া সমিতি আপডেট — দৈনিক কালেকশন কর্মী নির্বাচন, কাস্টম সদস্য নম্বর, মাসিক টার্গেট/অ্যাসাইনমেন্ট

ফাইল:
- index.html: আপডেট করা অ্যাপ
- firestore.rules: staffTargets-এর জন্য নিরাপদ read/write নিয়মসহ সম্পূর্ণ Rules
- module.js, logo.png, sw.js, manifest.webmanifest: পূর্ববর্তী ফাইল অপরিবর্তিত

নতুন ফিচার:
1. দৈনিক কালেকশন শিটে কর্মী নির্বাচন; নির্বাচিত কর্মীর নাম শিটে ও প্রিন্টে থাকবে।
2. সদস্য ভর্তি ফর্মে সদস্য নম্বর ঐচ্ছিক। নম্বর লিখলে সেটি ব্যবহার হবে; ফাঁকা রাখলে স্বয়ংক্রিয় নম্বর তৈরি হবে। ডুপ্লিকেট নম্বর আটকানো হয়।
3. অ্যাডমিনের কর্মী ব্যবস্থাপনা পেজে মাসভিত্তিক ঋণ বিতরণ ও কিস্তি কালেকশন টার্গেট, কাস্টম শুরু/শেষ তারিখ এবং অ্যাসাইনমেন্ট সংরক্ষণ/সম্পাদনা।
4. স্টাফ নিজের রিপোর্ট পেজে তার জন্য নির্ধারিত টার্গেট ও অ্যাসাইনমেন্ট দেখতে পাবে।

প্রকাশের আগে:
- বর্তমান সচল ফাইল ও Firestore Rules-এর ব্যাকআপ রাখুন।
- GitHub-এ index.html প্রতিস্থাপন করে commit করুন।
- Firebase Console > Firestore Database > Rules-এ এই ZIP-এর firestore.rules সম্পূর্ণ কপি করে Publish করুন। এতে আগের Rules অন্তর্ভুক্ত আছে এবং staffTargets collection-এর নিয়ম যোগ করা হয়েছে।
- লগইন, সদস্য নম্বর (ম্যানুয়াল/অটো), দৈনিক শিটের কর্মী নির্বাচন এবং টার্গেট সংরক্ষণ পরীক্ষা করুন।

পরীক্ষা: ZIP integrity এবং JavaScript syntax check করা হয়েছে। Firebase-এর বাস্তব ডেটা/অ্যাকাউন্টে সরাসরি পরীক্ষা করা হয়নি।
